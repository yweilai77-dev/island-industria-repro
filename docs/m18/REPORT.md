# M1.8 交付报告：跨层机械与完整工业生产闭环

> 生成时间：2026-11-07。基线 HEAD `076eb20`（M1.7 正式验收后的 autosave + M1.8 调查文档提交）。
> 验收方式：单元测试 / 类型检查 / 工程检查 / 生产构建 / **真实浏览器 playthrough（真实鼠标键盘）** / 15 分钟持续游玩。

## 0. 一句话结论

玩家可以**亲手**从采集铁矿石开始，搭建一座跨层的机械工厂：手摇飞轮储能 → 齿轮分流 → 立式传动带穿过楼板把动力送到二楼 → 破碎机把矿石打成碎铁矿 → 重力溜槽自动送到熔炼炉 → 炼出铁锭 → 锻压机把铁锭锻成传动轴 → 再用这根轴扩建工厂。跨层传动、正式动力源、正式加工机器、最小自动运输、完整生产闭环五项全部打通并各有独立 playthrough 断言。

### M1.8-B 正式动力来源（手摇飞轮储能）

- 新零件 `flywheel_source`（`kind: 'power-source'`，capacity 140 N·m，60 RPM）。
- **能量池**：容量 300；靠近（≤2.2m）按住 `C` 摇动摇柄 +45/s；离合挂上后按「空载 6/s + 负载 14/s×(需求/容量)」抽能。
- 交互：右键离合启停（与测试动力源同一套 `sourceToggleTarget`）；储量归零后**自动断开输出**，`solvePower` 看到源不可用 → 机器真的停转（不是动画停）。
- 旧「测试动力源」保留不动（历史验收脚本依赖 slot 4），两者在物品描述里明确区分。

### M1.8-C 正式加工机器

| 机器 | 配方 | 时长（额定 60RPM） | 额定负载 | 缓冲 |
|:--|:--|:--|:--|:--|
| 破碎机 `crusher` | 1 铁矿石 → 1 碎铁矿 | 4s | 18 N·m | in 4 / out 4 |
| 熔炼炉 `smelter` | 1 碎铁矿 → 1 铁锭 | 6s | 24 N·m | in 4 / out 4 |
| 锻压机 `forge` | 2 铁锭→传动轴 / 3 铁锭→立式传动带 / 2 铁锭→溜槽 | 5/6/4s | 22 N·m | in 6 / out 4 |

- 加工必须由机械动力驱动；**动力中断时进度冻结**（原料不消耗），恢复后从原进度继续。
- 周期开始时**整笔扣料**、整笔检查输出空间；失败则不开工，绝不半途扣料。
- 输出缓冲满时进度停在 1.0 等待，产物不丢。
- 交互：悬停机器按 `C` 从库存投 1 件原料、右键取货、`R` 循环配方（锻压机 3 条）。
- 加工速率 = 实际转速/额定转速 → 负载把整网转速压下去，加工就真的变慢。

### M1.8-D 物品运输与最小自动化

- 新零件 `chute`（重力溜槽，`kind: 'transport'`，无机械端口 → 不进入动力拓扑）。
- 每格最多 1 件物品，`t∈[0,1]` 真实位置，1.2 m/s 下滑；到槽口后交给下一格（溜槽/机器输入缓冲/末端存入库存）。
- 下游不可接收时停在 `t=0.92` 等待，**物品不复制、不消失**；上游因此自然堵塞、机器输出缓冲满 → 加工暂停（可观察、可恢复）。
- 机器物品出口固定在本地 +X 侧，自动把产物推给相邻溜槽。

### M1.8-E 完整生产闭环

- 生产链：铁矿石 →（破碎机）碎铁矿 →（重力溜槽）熔炼炉 → 铁锭 →（锻压机）传动轴。
- 铁锭可反哺建造：锻压出的传动轴真的进库存、真的能被放下去继续建厂（验收脚本实测库存 18→17、机械零件 15→16）。

## 3. 每项功能的实现方式（关键设计）

### 3.1 跨层传动为什么不需要锥齿轮

现有连接规则要求「锚点重合 + 轴平行」，所以「Y 轴 + localY 0/3」的立式轴接不上任何 1m 零件。M1.8 的解法不是加锥齿轮（那是模型级改造），而是把立式传动带做成：

- 高 3m，AABB `y[3L, 3L+3]`；
- 底部端口 `face nx, localY 0.5` → 世界锚点 `(gx, 3L+0.5, gz+0.5)`，正好等于**同层**水平轴端口；
- 顶部端口 `face px, localY 3.5` → 世界锚点 `(gx+1, 3L+3.5, gz+0.5)`，正好等于**上一层**水平轴端口。

于是「跨层」变成两次普通的轴向连接，动力/转速/扭矩/负载全部由现有 `solvePower` 处理，**没有第二套动力模型**，也没有任何"隔空传力"。叠层时上层立式带放在 `(gx+1, gz)`（斜向上），这是几何必然，测试里明确断言了这个限制。

### 3.2 开孔为什么能"合法穿层"

`SupportRegistry` 没有孔洞语义（只做加法）。M1.8 用**支撑面种类**表达孔：

- `deck`：`level L+1`、`worldY 3(L+1)`、buildable + **walkable**；
- `opening`：同层同高、buildable + **not walkable**、且**不注册碰撞体**。

结果：`buildableSupportAt` 让机械零件可以站在孔上继续向上连；`selectFlatSupport` 过滤掉 walkable=false，玩家走到孔边 `resolveMove` 返回 `moved:false`（空气墙，不会掉进洞里）；`opening` 没有碰撞体，所以 3m 高的立式传动带能穿过楼板那一格。支柱 2.7m + 楼板 0.3m 正好拼满一层，两个 AABB 只在边界贴合（`aabbIntersects` 不判相交）。

### 3.3 生产的原子性与"不丢物品"

- 加工的开始/完成都是**整笔事务**：先 `canStoreOutput` 再扣料/产出；任何一步不满足就退回等下一帧。
- 溜槽在途物品只有一个持有者（机器缓冲 / 溜槽 / 库存三选一），堵塞只改 `blocked` + 停在 0.92，不复制不销毁。
- 机器/溜槽被拆除时 `flushMachine` / `flushChute` 把物品交回库存。
- **playthrough 抓到过一个真实丢物品 bug**：`dt = 0` 的帧里加工机照常「整笔扣料」，但 `progress += 0` 不前进，下一帧又因进度为 0 重新要求整笔原料 → 两份铁锭凭空消失。已在 `tickMachine` 开头加零时间步保护，并补了回归测试。

### 3.4 读数与验收怎么定位格子

`mechanical` 快照新增 `ui.buildTarget / ui.hoveredPartId / ui.selectedPartId / ui.floorMode / player / production / inventory`。验收脚本据此在**真实鼠标**下做「屏幕 ↔ 格子」标定（仿射拟合 + 牛顿迭代），再真实点击放置；放置前断言目标格与 `valid`，不做"点了再看运气"。这套工具也顺手暴露了几个只有真机才会踩到的问题（相机 yaw 是 45°、机械放置朝向是全局累积状态、相邻高零件会遮挡射线）。

### 5.3 本轮真机验证抓到并修掉的问题

6. **摇柄键与采集键都是 F** → 摇柄改为 `C`。

## 7. 未完成事项与已知问题

1. **存档仍未实现（M1 范围内已明确归档）**：生产闭环不依赖存档（单次会话可完成），但生产链新增的「机器输入/输出/进度/储能/溜槽在途物品」都必须进快照才能持久化。方案见 `docs/design/SAVE-ARCHITECTURE.md`，M2 P0。
2. **立式传动带叠层是斜向上的**：level L 的顶端口在 `(gx+1, gz)`，所以第二段立式带必须放在相邻格。这是「端口必须与水平轴 0.5m 端口面重合」的几何必然，已写进单测断言；如果要同格直通，需要引入锥齿轮（模型级改造）。
3. **固定平台不能开孔**：玩家自建楼板可以开孔穿轴，但 M1.5 的固定平台（8×6）仍是单一实体碰撞体。R2 目标是"玩家亲手搭"，所以主流程走自建楼板；给固定平台开孔需要把它拆成逐格碰撞体（会动到 5 处历史断言），留给 M2。
4. **楼板悬挑无受力计算**：结构规则只有「本格有支柱 或 相邻格已有上层支撑」，理论可以无限向外悬挑。已在方案文档标注；M2 若要真实结构，需要跨距/承重模型。
5. **矿点总储量 80 且不再生**：单条产线每炼 1 铁锭消耗 1 矿石，够 15 分钟演示与多轮生产，但不可能"无限经营"。M2 考虑再生或更大矿脉。
6. **3D 读数面板尺寸偏大**（M1.7 就存在）：悬停读数会盖住半个屏幕，M1.8 未改动（UI 归 M2）。加工进度/堵料原因目前只在 GameRead 与塔吊动画里可见，还没有 DOM 生产面板。
7. **相机在长时间会话里会缓慢拉近**：`play.mouse` 系列操作后观察到变焦偏移，未定位到具体来源（`camera.pack.ts` 只由滚轮改变 `targetDistance`）。不影响玩法与验收，M2 相机/UI 阶段复查。
8. **快捷栏 12 格已满**（11 种零件 + 1 空槽）：再加零件必须先做「建造/零件菜单」，否则又会撞 `bind()` 越界。
9. 楼层建造没有 UI 提示：只有 `V` 进入后 3D 幽灵预览与网格高亮，快捷键和当前结构名没有 HUD 文案（M2 UI 任务）。
