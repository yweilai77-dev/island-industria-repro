## 5. 接口盒物品与数据定义（摘要）

- 物品：`interface_box`（基础接口盒），分类 `mechanical`（理由与后续拆分计划见 DESIGN §1.1）。
- 制造：锻压机第 4 条配方 `forge-interface-box`：2 铁锭 → 1 接口盒，5 s（额定速率）。
  追加在列表**末尾**，前三条 R 切换顺序不变，订单判定不受影响。
- 绑定：`port.through.itemId = interface_box`；分流/合流盒仍 `null`（P2-C）。
- 静态/运行时分离：静态是 `PortModuleDef` 与 `portSlots`；运行时是 `PortRuntime` 的
  `InstalledPort { partId, slot, module, itemId, count }`。**加工状态不在接口盒里。**

## 6. 安装位数据与空间关系（摘要）

- 安装位 ID：`slot.<core>.in.nz` / `slot.<core>.out.px`；每个核心 1 输入 + 1 输出。
- 世界坐标：`slotWorldOf(part, slot)` 复用 `mechanical/ports.ts` 的 `portWorld`，
  与机械端口同一套换算；输出 anchor / outward / center / yaw。
- 旋转：视图每帧按机器当前 `Placement` 重算；新增 `U` 旋转加工核心（仅核心）。
- 进入方向：`incomingDirectionOf` = 面外法线反向；溜槽必须正对这个方向才算连接。

## 7. 安装 / 拆卸 / 更换流程（摘要）

`T` 安装（背包扣 1）、`Y` 拆卸（返还 1 + 盒内物料全部交回）、`U` 旋转核心。
「更换」= `Y` 再 `T`（P2-B 只有一种接口盒，不需要额外 UI）。
失败分支（无物品 / 位被占 / 规格不符 / 未绑物品）全部是「无操作、不扣物品」；
运行中允许安装/拆卸；连接是几何派生的，拆盒即断开；拆机时整盒与缓冲一起交回。

## 8. 自动输入数据流（摘要）

`机器 → 溜槽 →（方向对 + 已装输入盒）→ 接口盒缓冲 →（原子 drain）→ 机器输入缓冲 → tickMachine`。
每帧先 drain 再加工；盒满拒收、机器满则盒保留；断电不影响转移、也不产生重复；
堵塞物品每帧原地重试，下游恢复后自动继续。

## 9. 流槽与接口盒职责边界（摘要）

| | 流槽 | 接口盒 |
|:--|:--|:--|
| 手动投料 | ✅（悬停机器按 C / 右键，直接进机器缓冲） | ❌ |
| 自动输入机器 | ❌ 必须经接口盒 | ✅ 唯一通道 |
| 机器产物自动输出 | ✅ 保留（M1.8 行为不变） | P2-C |
