### 5.2 失败归因（按证据分类）

1. **测试脚手架输入可靠性（主因）**：`project play` 的 CDP 输入在长脚本里偶发整帧丢弃/挂起（`keyboard.hold` 卡住、`advance` 卡住）。同一套按键在短脚本与独立探针里稳定（采集探针 60 次 60/60）。这是 E1 已记录的采集 flaky 的放大形态。
2. **脚本自身的健壮性**：第一版盲按固定次数、固定等待、hover 不稳定；本阶段已改为状态驱动 + hold + 校验重试，逐步收敛，但仍未在有限轮次内跑通。
3. **不是游戏逻辑缺陷**：同样的系统在分段真实游戏验收里全部通过（见 §6），单测/集成测试 822 例全绿。
