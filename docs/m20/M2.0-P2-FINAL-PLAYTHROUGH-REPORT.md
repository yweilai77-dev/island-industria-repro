## 4. 与「不做假测试」相关的声明

- 科技交付全部通过 `__II_TEST_TECH__`（player 模式下仅当 `techHooks` 开启时暴露）发送与正式 UI **完全相同的协议命令**，走真实事务（校验节点/材料/数量 → 扣库存 → 写进度），不注入材料、不写完成标记。
- 终局运行证明通过 `__II_TEST_ENDGAME__.beginProof()` 触发与 UI 按钮相同的命令；窗口内的产出必须来自真实加工（`tickMachine`）、真实动力（`power.ts`）与真实物流。
- 唯一 GameRead `mechanical` 是全部断言的读投影；脚本不读内部变量、不调用调试接口。
