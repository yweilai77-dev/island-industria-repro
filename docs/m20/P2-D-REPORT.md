## 5. 结构模块（摘要）

- 真实物品 `structure_frame`（结构框架）：可持有、可堆叠、有图标与操作说明；
- 真实机械零件 `structure_frame`：`kind='structure'`、1×1、高 1、无动力端口、不传扭矩；
  走既有放置事务（空间/支撑/玩家碰撞校验）与既有拆除返还；
- 静态定义 `structure.frame`：连接方式 `orthogonal`、reach 1、可连 core 与 module；
- 世界表现：上下钢板 + 四角橙色立柱 + 螺栓，与深灰机器/砖红炉体明显区分；
- 获取（**临时原型供给，P2-E 统一调整**）：锻压机配方 `forge-structure-frame`（3 铁锭 → 1，5 秒）+ 开局 4 个。

## 6. Assembly 运行时（摘要）

- 节点 = 加工核心 + 结构模块；结构边 = 同层正交相邻且至少一端是结构模块；
  核心—核心直接相邻**不**构成结构关系；
- 连通组件中加工核心 ≥2 才形成组合；结构模块串联可表达直线/转角/T 形；
- `AssemblySnapshot extends Assembly`（P2-A 的 id + memberIds），只增加只读管理字段：
  成员/模块表、结构关系、相对位置与方向、整体边界、成员额定扭矩之和；
- 不持有成员加工/缓冲/动力状态；不含速度/产能字段（单测断言）；
- ID 稳定策略：新组件分配 `assembly:<serial>`；有交集的候选沿用旧 ID；
  合并保留最早 ID；拆分低 partId 侧保留；serial 不复用。

## 7. 组合建立与成员管理（摘要）

| 操作 | 行为 |
|:--|:--|
| 放置核心 | 与 P2-D 之前完全一样（真实放置事务） |
| `P` / 左键 / `Esc` | 结构放置模式：绿/红幽灵、悬停格目标读数、左键放置、退出 |
| 合法性 | 目标格必须与同层核心或结构模块正交相邻 + 既有空间/支撑/碰撞校验 |
| 失败 | 不扣物品、不写世界；无半完成组合 |
| 查看 | 唯一 GameRead `assemblies` + `ui.selectedAssemblyId`；选中成员/框架显示边界与标记 |

## 8. 整体空间与选择（摘要）

- 边界 = 全部成员与结构模块真实占格并集 + 最大高度（世界 AABB）；
- 相对位置/方向 = 相对 partId 最小成员的格偏移与旋转差；
- 选中任一成员或结构模块 → `ui.selectedAssemblyId`；世界绘制 12 条边框光条 +
  成员核心琥珀立柱 + 结构模块青色立柱；成员核心仍可单独选中与操作；
- 本阶段不做整体移动/整体旋转。

## 9. 拆解与状态恢复（摘要）

- 结构框架用现有 `Delete` 拆除：物品返还 1 次；下一帧推导自动缩小/解除组合；
- 不触碰端口/物料连接/加工状态/缓冲；拆成员核心同理；
- 无“模块已返还但组合仍在”的中间态；实体 ID 全程不变；
- 真实游戏 F：拆框后组合解除、两个框架精确返还、连接/端口/物料/进度原样；
  重搭后生成新 Assembly ID 且成员核心 ID 不变。

  一次连通组件遍历，无定时器、无协程、无每帧分配大对象（快照只在变化时更新服务缓存）；
- 边界视图最多 12 条光条 + 每个成员/模块 1 个标记，随选中组合变化，不随组合数增长；
- 真实游戏验收 376 步 / 234.5 s，控制台 0 错误，1280×720 稳定渲染。

### 14.2 已知限制

1. **只有一种结构模块（1×1 结构框架）**：直线/转角/T 形靠多个框架串联表达；
   没有专用 1×N 梁、转角件或承载等级（任务书明确本阶段优先最小可靠实现）。
2. **组合整体选择是“世界视图 + 只读投影”**：边界光条、成员/结构标记、`assemblies` 数据；
   没有新增成员列表面板/HUD（任务书要求避免无关 HUD 重构）。
3. **不做整体移动/整体旋转**（任务书 §五.6/7 明确禁止）。
4. **组合状态未存档**：与端口/生产状态一致，当前没有存档系统；读档相关一起做。
5. **结构模式中不能拆零件**：`P` 模式让出机械输入；要拆除需先退出模式（`P`/`Esc`）。
6. **成员旋转会按 P2-C 规则使物料连接失效**：1×1 占格不变、组合不受影响；
   连接需要转回原朝向后自动恢复（场景 G 验证）。
7. **真实游戏未覆盖“拆除组合成员核心”**：单测覆盖（其余成员仍成组、ID 不变）；
   真实游戏 F 只拆除结构框架（任务书场景 F 的要求）。
8. **不同楼层不能组成同一组合**：结构连接要求同层；跨层组合留待未来结构体系。
9. **嵌套组合不支持**：一个核心只能属于一个独立组合；合并两个组合会在世界几何上
   变成一个组合（任务书 §三.P2-D-1.10 允许未来再讨论嵌套）。
10. **结构框架/配方是临时原型供给**：P2-E 统一决定机器获取与科技解锁。
