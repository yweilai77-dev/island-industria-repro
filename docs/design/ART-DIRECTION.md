# 美术方向调查（M1.8）

> 目的：在 M1 收官前定下视觉方向，避免 M2 边做模型边改风格。本文只做方向与可行性判断，
> 不产出最终资产；选定后写成 `docs/design/ART-BIBLE.md`（含色板、比例、材质与命名规范）。

## 1. 现状（截图证据）

| 项 | 现状 | 问题 |
|:--|:--|:--|
| 地形 | 32×32m 平地 + 四段深灰包边 | 没有岛、海岸线、远景 |
| 材质 | 3 个纯色 Standard 材质（地面/方块/包边），无贴图 | 地面/岩石/木材/金属无法区分 |
| 天空 | 相机 `clearColor` 深蓝灰 | 没有天空、太阳、云、海 |

| 模型 | 程序化 Box/圆柱：蓝绿紫方块建筑、灰色齿轮、橙色矿簇 | 灰盒测试感，没有统一风格 |
| UI | DOM 深色面板 + 8 格快捷栏 + 3D 方块数字 | 与 3D 世界两套语言 |
| 调试信息 | 左上角 `Game <hash> | Engine 0.4.19 | FPS` | 由预览宿主注入，交付前必须处理 |

## 2. 引擎可用的表现力（技术可行性）

从 SDK 技能文档确认可用，不需要改引擎：

- **材质**：`MaterialAsset`（Standard/PBR）支持贴图（`TextureAsset`，含 sRGB/线性/KTX2），
  金属度/粗糙度/自发光；可用 WGSL 自定义材质做海面、能量线。
- **天空**：Pack 内生成 HDR `EquirectAsset` → `SkyboxBackground` + `Skylight`（同一张图同时
  供背景与 IBL）；物理大气用 `Atmosphere`。
- **光照/阴影**：1 个方向光（lux + 级联阴影）、Skylight 半球光、最多 256 个局部光
  （点光/聚光/面光 + IES 分布），可做熔炉/炉火/警示灯。
- **后处理**：RenderPipeline/RenderGraph 有后处理通道，可做 bloom / 暗角 / 色调映射
  （当前已用 ACES tonemap + FXAA）。
- **特效**：VFX 粒子（蒸汽、烟、火花、尘土）可用。
- **音频**：`@forgeax/engine-audio` + Host 侧 WebAudio 插件，支持 BGM/SFX/空间音源
  （当前工程尚未接入，M2 前期接）。

## 3. 三个候选方向

| 方向 | 描述 | 优点 | 风险/成本 |
|:--|:--|:--|:--|
| A. 低多边形海岛（推荐） | 平面着色低多边形；饱和海蓝 + 暖色工业橙；几何化棕榈/岩石/废墟；海面简单波动；黄昏/正午两种光照 | 俯视可读性最好；程序化几何在 Pack 里可控；建筑/机械方块天然契合；成本最低 | 容易显得“玩具”；需要靠比例、剪影、色调拉开层次 |
| B. 桌面模型/纸艺立体书 | 整座岛像桌上的微缩模型；纸板/木纹材质；柔和台灯；边缘可见“桌面” | 辨识度极高，和“自由搭建”气质契合，评委记得住 | 每个资产都要手工感；俯视下“桌面边框”可能干扰操作；一致性难 |
| C. 半写实工业海岸 | PBR 锈蚀金属/混凝土/岩石贴图；阴天海雾；高密度细节 | 最接近参考作品（Satisfactory/Frostpunk） | 资产量最大、最容易风格不统一；当前团队是程序化资产，写实贴图来源是硬约束 |

## 4. 推荐：A（低多边形海岛 + 暖色工业）

理由：

1. **成本**：几何体 + 平面着色 + 少量贴图即可成立，和现有程序化 Box/圆柱资产是同一路线，
   M2 能在不推翻代码的前提下替换视觉。
2. **可读性**：八方向俯视 + 小屏幕下，低多边形的大色块比 PBR 细节更容易分辨
   「地面 / 平台 / 机械 / 资源」。
3. **一致性**：玩家自建方块、机械零件、岛屿地形可以共用一套低多边形语言，不会出现
   "写实海岛 + 方块工厂" 的割裂。
4. **可升级**：M3/M4 若要做写实化，低多边形资产可以逐类替换；B 的"微缩模型"框架也可以
   作为 M4 的表现彩蛋（例如主菜单是一座沙盘）。

## 5. M2 落地计划（按依赖排序）

1. **色板与光照**：定 12 色主色板（海/沙/岩/木/铁/锈/警示橙/面板深灰…）；正午 + 黄昏两套
   方向光/天空参数；全局 tonemap/exposure 校准。
2. **地形**：岛屿高度场网格（边缘下降入海）+ 沙滩/草地/岩石三种材质；海面平面 + 简单
   法线波动（WGSL）；天空 HDR equirect；远景雾。
3. **资源与建筑**：矿簇、树木、岩石、平台/楼梯、三种建筑换成低多边形模型；统一比例
   （1 格 = 1m）与倒角风格。
4. **机械**：齿轮（带齿廓）、传动轴（带法兰）、动力源（锅炉/飞轮）、冲压机（机架+冲头）
   的低多边形模型 + 运转动画（已有 angle 驱动，替换 mesh 即可）。
5. **特效**：采矿尘土、机器蒸汽/火花、过载冒烟（用现有 VFX 能力）。
6. **UI 与 3D 统一**：见 `UI-SPEC.md`；3D 数字 HUD 要么改成世界内铭牌，要么并入 DOM UI。
7. **截图验收**：固定机位截「开局 10 秒」「工厂全景」「机械特写」，三张都能当宣传图。

## 6. 验收标准

- 第一眼（不操作、3 秒）能说出「这是一座岛上的工厂」。
- 地面/岩石/木材/金属四种材质在同屏可区分（灰度截图也能区分明度层次）。
- 建筑与机械属于同一套形状语言（倒角/比例/配色一致）。
- 没有调试视觉：网格线默认关闭或弱化，左上角调试条不在交付画面里。
- 性能：M2 目标场景 ≤ 预算（见 `PERFORMANCE-BUDGET.md`）。

## 7. 待用户确认

- 时间氛围：正午明亮 vs 黄昏暖色（影响所有截图与宣传图）。
