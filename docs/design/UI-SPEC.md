# UI 视觉与交互规范（M1.8 调查）

> 目的：现有界面已经能完成任务，但还没有统一语言。本文盘点现状、定下 token 与组件规则，
> 作为 M2 全部 UI 改造的唯一依据。改动落地时以本文为准，不在各文件里各写一套颜色。

## 1. 现状盘点

| 界面 | 实现 | 现状 |
|:--|:--|:--|
| 快捷栏（8 格） | `frontend/frontend-ui.ts` + `frontend-ui-styles.ts` | DOM，深蓝面板、青色选中、数字/图标/数量齐全，可拖拽绑定 |
| 背包 | 同上 | DOM 模态：列表 + 详情 + 拖拽，`Tab`/`Esc` 开关，打开时暂停 |
| 提示 | 同上 | 只有一行「Tab 打开背包」 |
| 矿石计数 / 采集进度 / +1 / 枯竭 | `harvest.pack.ts` 用 Box 实体拼 7 段数字 | 3D 方块数字，与 DOM UI 两套语言 |
| 机械读数 | `mechanical/readout.ts` 相机锚定 | 3D 卡片，显示转速/扭矩/状态 |
| 建造幽灵 / 朝向标记 / 选中轮廓 | `build.pack.ts` 半透明实体 | 3D，绿色合法 / 红色非法 |
| 建造类型 | `[` `]` 切换 `shed/block/hall` | **没有任何 UI 告诉玩家现在选的是哪种、有哪几种** |
| 调试条 | 预览宿主注入在 `dist/index.html` | `Game <hash> | Engine 0.4.19 | FPS`，交付画面必须没有它 |

## 2. 发现的问题（按影响排序）

1. **建造不可发现**：3 种建筑只能靠 `[`/`]` 盲切，玩家不知道存在、也不知道当前选了什么。
   M2 必须有建造菜单（图标 + 名称 + 尺寸 + 当前选中）。
2. **没有键位说明**：除 `Tab` 外，`R`/`X`/`G`/`Q`/`E`/`1-8`/`[`/`]` 全靠猜或开发者口述。
3. **两套视觉语言**：DOM 是冷蓝科技风，3D 世界是灰/橙/米色；矿石数字是方块像素风。
4. **反馈不全**：错误只显示在背包标题栏（背包关着时看不到）；建造失败只有幽灵变红。
5. **没有状态层**：没有暂停菜单、设置、保存提示、目标/任务提示。
6. **机械信息不可持续查看**：读数是相机锚定的世界卡片，多个机器同屏会挤，也没有"选中机器
   → 侧栏详情"的路径。
7. **对比度**：`#7f97ad` 小字在 `#0c141d` 上对比约 4.0:1，12px 时偏弱；绿色/红色对
   色弱玩家区分度低（只靠颜色）。
8. **布局风险**：AGENTS 要求 1280×720 与 1280×600 下 HUD 不重叠/不裁切；当前提示条
   `bottom: 88px` 与 56px 快捷栏在 600 高度下余量偏小，需要固定安全区。

## 3. 设计 token（建议定稿）

```text
# 颜色（深色工业面板 + 暖色强调）
--ii-bg-0      #0B1219   最深底（游戏外的全屏遮罩）
--ii-bg-1      #0F1A25   面板底
--ii-bg-2      #16222E   次级面板 / hover
--ii-line-1    #22303D   分隔线
--ii-line-2    #33475A   控件边框
--ii-text-1    #E8F3FF   主文字
--ii-text-2    #9FB3C8   次文字
--ii-text-3    #6F8AA3   弱文字（≥12px 才用）
--ii-accent    #E8873A   工业橙：主强调、选中、标题
--ii-info      #57D4FF   钢青：信息 / 绑定标记
--ii-ok        #7DFF9B   合法 / 成功
--ii-warn      #FFC857   警告 / 过载
--ii-danger    #FF6B5A   非法 / 故障

# 字体与字号
font: "Segoe UI", "Microsoft YaHei", system-ui, sans-serif
字号：11 辅助 / 12 说明 / 13 正文 / 14 控件 / 17 面板标题 / 20 大标题 / 28 数字强调
数字用 tabular-nums，避免转速跳动时抖动

# 间距（8 基准）
4 / 8 / 12 / 16 / 24 / 32
圆角：控件 6，面板 12，大面板 14
阴影：面板 0 12px 32px rgba(0,0,0,.55)

# 动效
hover 120ms、面板 160ms、提示 180ms，ease-out；不做位移超过 8px 的弹跳
```

## 4. 组件规则

- **Slot（56×56）**：图标 32px 居中，左上角键位 10px，右下数量 12px；选中用橙色描边 +
  外发光；绑定物品用钢青小徽标，不重复画图标。
- **Panel**：标题栏 17px/700，右上角关闭按钮；内容区 13px；滚动条只在内容溢出时出现。
- **Button**：高 32px，内边距 12px；主按钮橙色描边，次按钮灰描边。
- **Toast**：屏幕上方 1/4 处，单行，最多 2 条堆叠；成功/警告/错误用图标 + 颜色双编码。
- **Keycap**：12px、边框 `--ii-line-2`、圆角 4，用于键位提示。
- **Tooltip**：跟随鼠标，200ms 后出现；只放一句说明，不放参数表。
- **Progress**：采集/生产进度统一为细条（高 6px），背景 `--ii-bg-2`，填充 `--ii-accent`。
- **状态色双编码**：合法/非法除颜色外必须有 ✓/✕ 图标或轮廓线型差异，照顾色弱。

## 5. 布局与安全区

- 基准 1280×720，同时验 1280×600；所有 HUD 必须在 24px 安全边距内。
- 快捷栏：底部居中，距底 18px；提示条上移 24px 或其上 16px，避免与 600 高度冲突。
- 左上角：目标/任务（M2）；右上角：机械/生产信息（可选面板）；底部：快捷栏。
- 建造菜单：底部快捷栏上方的横向条（可展开 2 行），不遮挡中心准星区域。
- 世界内 3D 文字（矿石计数、机器读数）：统一改为 DOM 覆盖层或世界内铭牌，二者只留一种。

## 7. 验收标准

- 1280×720 / 1280×600 下无重叠、无裁切（`project play` 的 layout 警告为空）。
- 全新玩家不看说明，30 秒内能：打开背包、选中物品、切换建造类型、放下一个建筑。
- 所有可交互元素有 hover / active / disabled 三态；所有失败有可见文字反馈。
- 全界面只使用本文的 token；新增颜色必须先进本文。
