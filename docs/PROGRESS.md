## 0. 一句话结论

**M1 系列完成。** 玩家可以从采集铁矿石开始，亲手搭一座跨层机械工厂：手摇飞轮储能 →
齿轮分流 → 立式传动带穿过楼板把动力送到二楼 → 破碎机 → 重力溜槽 → 熔炼炉 → 铁锭 →
锻压机把铁锭锻成传动轴再拿去扩建。整体仍处 L2（玩法成立），拖住 L3 的是美术、音效、
UI 规范、存档与目标引导——正是 M2 的范围。
