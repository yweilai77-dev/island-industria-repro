# Demo 验收清单与演示脚本

> 用途：每个里程碑结束时逐项打勾。**打勾必须有证据**（playthrough 步骤名、截图路径、
> 测试名或视频时间点），不能凭印象。规则见 `docs/ROADMAP.md` §6。

## 1. L2 · 玩法成立（M1 结项用）

### 1.1 技术门

- [ ] `pnpm exec forgeax project check --json` → `ok: true`
- [ ] `pnpm test` → 全绿
- [ ] `pnpm typecheck` → 通过
- [ ] 构建成功，`dist/` 产物晚于最后一次代码提交
- [ ] 主 playthrough 在最终代码上通过，console 0 / page 0

### 1.2 玩法门（从启动到闭环，全程不看代码）

- [ ] 启动后 5 秒内可操作，没有报错弹窗
- [ ] WASD 移动、Q/E 转视角、滚轮缩放正常，镜头不穿地
- [ ] 走到矿点，按住采集键：进度条出现，3 秒后背包 +1
- [ ] 矿点采空后显示枯竭，不能再采
- [ ] `Tab` 打开背包，能把物品拖到快捷栏，关背包恢复移动
- [ ] `[`/`]` 切换建筑、`R` 旋转、左键放置、`X` 拆除
- [ ] 非法位置有红色幽灵 + 无法放置反馈
- [ ] 选中机械零件，放在地面/平台上，`R` 旋转，`X` 拆除并返还库存
- [ ] 动力源 ↔ 传动轴 ↔ 齿轮 ↔ 机器 能连成网络
- [ ] 右键启停动力源：机器开始往复，读数显示转速/扭矩/状态
- [ ] 12T↔24T 啮合：转速减半、方向相反
- [ ] 增加负载：转速下降（速度下垂）；过载：整网/支路停转；卸载后恢复
- [ ] **跨层传动：一楼动力经结构送到二楼机器**（待 M1.7-D）
- [ ] **首条生产链：矿石 → 机器加工 → 成品 → 入库，成品能反哺建造**（待 M1.8-A）
- [ ] **退出/刷新后继续**：工厂、库存、矿量、启停状态一致（待 M1.8 存档）

### 1.3 体验门

- [ ] 找 1 名没看过项目的人，只给键位表，20 分钟内完成「采 5 个矿 → 建 1 个平台 →
  放 1 套动力 + 1 台机器 → 启停」；记录所有卡住的地方
- [ ] 卡住点全部修复或写进 M2 待办
- [ ] 按 `docs/ROADMAP.md` §3 八维打分，写进 `docs/PROGRESS.md`

## 2. L3 · 游戏完整（M2 结项用）

- [ ] 主菜单：开始 / 继续 / 设置 / 退出
- [ ] 暂停菜单：继续 / 设置 / 保存 / 返回主菜单
- [ ] 设置：音量、画质（低/中/高）、镜头灵敏度、全屏
- [ ] 存档：手动保存 + 自动保存 + 读档；损坏存档有提示不崩
- [ ] 新手引导：第一步任务 + 目标提示 + 完成反馈
- [ ] 至少一条完整生产链稳定可重复运转
- [ ] 岛屿地形、海岸、天空、材质区分、统一美术风格（`ART-DIRECTION.md`）
- [ ] 音效：环境、采集、建造、拆除、机械运转、生产完成、故障/过载
- [ ] UI 统一：HUD/快捷栏/背包/建造菜单/机械信息使用 `UI-SPEC.md` token
- [ ] 1280×720 与 1280×600 无 HUD 重叠/裁切
- [ ] 交付画面无调试条、无开发用网格线（或可关闭）
- [ ] 性能：S 档 60 FPS，M 档 ≥ 45 FPS（`PERFORMANCE-BUDGET.md`）

## 3. L4 · 比赛交付（M5 结项用）

- [ ] 独立运行：解压/启动包，双击即玩，不依赖开发环境
- [ ] 3 名外部试玩者独立完成演示流程，无崩溃/卡死/无法继续
- [ ] 连续游玩 30 分钟稳定；存档/读档 3 次一致
- [ ] 演示视频 3–5 分钟 + 宣传截图 5 张 + 项目介绍一页
- [ ] 一句话定位、操作说明、键位图齐备
- [ ] 比赛章程要求逐项核对（拿到章程后补）

## 4. 演示脚本草案（5–10 分钟，给评委看）

| 时间 | 画面/操作 | 要传达的点 |
|:--|:--|:--|
| 0:00 | 主菜单 → 开始 | 完成度：这是游戏，不是场景 |
| 0:20 | 岛屿出生点，镜头缓动，任务提示「先采 5 块铁矿」 | 世界与目标 |
| 0:45 | 走到矿点，按住采集，进度条 + 音效 | 操作反馈 |
| 1:20 | `Tab` 打开背包，绑定快捷栏 | UI 完整 |
| 1:50 | 建造平台/楼梯，上到二楼 | 三维建造 |
| 2:40 | 放动力源 → 传动轴 → 齿轮（幽灵预览、旋转、合法/非法反馈） | 自由组装 |
| 3:30 | 右键启动，机器开始运转，读数出现，镜头推近齿轮 | 动力真实传递 |
| 4:10 | 加第二台机器：转速下降 | 负载影响运行 |
| 4:50 | 矿石送入机器 → 加工进度 → 成品入库 | 生产链闭环 |
| 5:40 | 成品反哺：用成品造下一个零件/扩建 | 产线成长 |
| 6:30 | 保存 → 退出 → 重新进入 → 工厂还在 | 完整性 |
| 7:00 | 全景 + 一句话定位收尾 | 辨识度 |

> 生产链与跨层传动完成前，4:50/5:40 两步先空着，其余步骤现在就能演。
